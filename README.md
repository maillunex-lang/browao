# BrowAO

Текстовый браузерный прототип BrowAO для мобильного экрана. В атласе можно открыть северную Адриатику, пройти контракты и улучшить отряд. В разделе «Учения» доступны исходные три PvE-боя.

## Запуск

Нужны Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Чтобы открыть прототип на телефоне в той же локальной сети, запустите `npm run dev -- --host 0.0.0.0` и откройте на телефоне адрес, который Vite покажет в строке Network.

```sh
npm run build
npm run preview
```

В бою выберите бойца, карточку приказа и подсвеченную цель. План можно скорректировать до подтверждения хода. После победы станет доступна следующая встреча. В атласе и на маршруте прогресс сохраняется в браузере. Текущий бой и прогресс учений живут до перезагрузки страницы.

## Онлайн-MVP

Для игры на двух устройствах соберите клиент и запустите сервер из корня проекта.

```sh
npm ci
npm run build
HOST=0.0.0.0 npm start
```

Откройте `http://<IP компьютера>:4174/#online` на устройствах в одной сети. Зарегистрируйте два аккаунта в отдельных браузерах или профилях. В общем зале один игрок приглашает другого, второй принимает приглашение. В бою ведущий управляет командиром и стрелком с двумя очками приказов, напарник управляет защитником с одним очком. Раунд завершается, когда оба подтвердили ход или истекла минута.

SQLite по умолчанию хранит данные в `data/world.sqlite`. Путь можно задать через `BROWAO_DB`, порт через `PORT`. Для разработки запустите `npm run server` и `npm run dev` в разных терминалах. Vite пересылает запросы к серверу на порт 4174.

Онлайн-аккаунты сохраняют чат, приглашения, бои и награды за кооператив. Одиночные контракты атласа сохраняются отдельно в браузере. Команда выше рассчитана на локальную сеть. При размещении за HTTPS-прокси задайте `BROWAO_SECURE_COOKIE=1`.

## Геоданные

Береговые линии взяты из Natural Earth v5.1.2, данные в общественном достоянии. Для глобальной карты используется слой суши 1:110 млн, для региональной — 1:10 млн. Скрипт `npm run atlas` загружает эти слои и готовит геометрию через d3-geo. Обычная сборка берёт готовый файл из репозитория. [Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2) · [d3-geo](https://github.com/d3/d3-geo)

## Демо без установки

Скачайте [browao-demo.html](https://github.com/maillunex-lang/browao/blob/demo/browao-demo.html) и откройте файл в браузере. Внутри уже есть карта мира, маршрут по Адриатике и три PvE-боя. Для сборки этого файла из исходников запустите `npm ci` и `npm run demo`. Готовый файл появится в `dist/browao-demo.html`.

Для кооператива в [ветке демо](https://github.com/maillunex-lang/browao/tree/demo) есть отдельная сборка с сервером. Она запускается на Node.js 24.
