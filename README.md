# BrowAO

Текстовый браузерный прототип пошаговых сражений для мобильного экрана. В «Полевых учениях» три связанных PvE-боя.

## Запуск

Нужны Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Чтобы открыть прототип на телефоне в той же локальной сети, запустите `npm run dev -- --host 0.0.0.0` и откройте на телефоне адрес, который Vite покажет в строке Network.

```sh
npm run build
npm run preview
```

В бою выберите бойца, карточку приказа и подсвеченную цель. План можно скорректировать до подтверждения хода. После победы станет доступна следующая встреча. Прогресс прототипа хранится в открытой странице.
