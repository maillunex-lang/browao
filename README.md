Две сборки BrowAO для первого знакомства с игрой.

- **browao-demo.html** — скачайте файл и откройте его в браузере. В демо есть карта реальной Земли, маршрут по северной Адриатике, три PvE-боя, контракты и улучшение отряда.
- **browao-coop.zip** — готовая сборка для игры вдвоём в одной сети. Нужен Node.js 24. Команды запуска для Windows, Linux и macOS есть в README.txt внутри архива.

Одиночное демо не требует аккаунта. Для кооператива каждый игрок создаёт аккаунт на запущенном сервере.
